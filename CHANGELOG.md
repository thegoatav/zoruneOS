# Changelog

## 0.1.0 — first preview

- Added a searchable desktop launcher, app windows, and appearance and accessibility settings.
- Added local productivity apps: Files, Notes, Paint, Calendar, Tasks, Photos, Clock, and Calculator.
- Added the Scramjet-based Browser, Global Chat, LuminSDK games with an offline fallback, and local music playback.
- Added Movies with TMDB catalog search and direct-media playback.
- Added App Creator with an isolated live preview and standalone HTML export.
- Restricted the local server to serving the desktop's public assets, and added release/setup documentation.
